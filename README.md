# ✈️ Airline Performance Dashboard

A modern and interactive Airline Performance Analytics Dashboard built using Power BI.  
This dashboard provides deep insights into airline operations, delays, passenger trends, flight performance, and route analysis through a premium dark-themed UI.

---

# 📌 Project Overview

The Airline Performance Dashboard helps analyze airline operational performance using interactive visualizations and KPI metrics.  

The dashboard focuses on:
- Flight performance tracking
- Delay analysis
- On-time performance monitoring
- Passenger trends
- Load factor analytics
- Route and destination analysis

The project is designed with a futuristic airline analytics theme inspired by enterprise-level dashboards.
